Da ideia à aplicação de IA

Um fluxo prático para construir aplicações com IA generativa: defina o problema, prepare dados, crie prompts, use embeddings, adicione RAG, avalie respostas, monitore e itere.

💡
1. Defina o caso de uso
Ex.: chatbot de atendimento, busca semântica, resumo de documentos, geração de relatórios.
📚
2. Organize dados e contexto
Colete PDFs, páginas, documentos, bancos de dados e regras de negócio.
🧠
3. Escolha modelo e arquitetura
LLM via API, modelo local, RAG, agentes, tool calling ou fine-tuning.
📊
4. Avalie, monitore e melhore
Meça qualidade, custo, latência, segurança, alucinações e satisfação do usuário.

# Instale: pip install tiktoken
import tiktoken

texto = "Modelos de linguagem transformam texto em tokens."
enc = tiktoken.get_encoding("cl100k_base")
tokens = enc.encode(texto)

print(tokens)
print("Quantidade de tokens:", len(tokens))
print("Reconstrução:", enc.decode(tokens))

Use contagem de tokens para controlar custo, latência e tamanho da janela de contexto.

# Exemplo conceitual com sentence-transformers
# pip install sentence-transformers scikit-learn
from sentence_transformers import SentenceTransformer
from sklearn.metrics.pairwise import cosine_similarity

modelo = SentenceTransformer("all-MiniLM-L6-v2")
docs = [
    "RAG combina busca de documentos com geração de respostas.",
    "Fine-tuning adapta um modelo para uma tarefa específica.",
    "Bancos vetoriais indexam embeddings para busca semântica."
]
pergunta = "Como recuperar documentos parecidos com uma consulta?"

emb_docs = modelo.encode(docs)
emb_q = modelo.encode([pergunta])
scores = cosine_similarity(emb_q, emb_docs)[0]

for doc, score in sorted(zip(docs, scores), key=lambda x: x[1], reverse=True):
    print(round(score, 3), doc)
